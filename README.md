## 三档Pro到底差在哪

### 用量：5x、10x、25x是什么概念

Pro 100的额度是Plus的5倍，Pro 200是10倍，Pro 500是25倍。ChatGPT Work和Codex共用同一份额度，不分开算。

一个容易被忽略的细节：所有Pro档位在Work和Codex里都没有Plus那种5小时使用限制，你可以把每周额度按自己的节奏用完，Plus目前还保留这个限制，而且官方员工明确表示不会把它加回Pro。

聊天里的GPT-6 Pro有独立的每周上限，任何档位都不是无限的。Pro 100上，GPT-6 Pro和GPT-5.6 Sol Pro共享一个每周额度；Pro 200上，GPT-6 Pro的每周额度用完后，ChatGPT会自动切换到Medium档的GPT-5.6 Thinking继续用。

### Ultrafast：Pro 500独有的高速模式

Ultrafast是OpenAI的高级速度档。GPT-6 Astra Ultrafast在Codex里生成token的速度最高可达标准模式的8倍，峰值约每秒300个token，在模型选择器里手动选用。GPT-6.1 Sol Ultrafast官方说即将推出。

这里有个容易踩的坑：Ultrafast烧额度的速度也快得多。官方给出的消耗倍率是，标准模式1倍，Fast模式2.5倍，Ultrafast 8倍；如果用购买的credits支付，分别是1倍、2倍、6倍。换句话说，把Pro 500的25倍额度全部跑在Ultrafast上，实际效果大约只相当于标准速度下的3倍Plus。速度和总量，很难两头都占。

还有一点要记住：Pro 100和Pro 200在上线初期买credits并不能解锁Ultrafast，这个模式目前只属于Pro 500，外加符合条件的Enterprise和Edu账户。

### 三档共同拥有的东西

核心功能三档一致：聊天里的GPT-6 Pro模型、Work和Codex里的GPT-6 Astra、最大记忆容量和100GB存储、deep research、图像生成、文件上传、新工具和模型的抢先体验，以及无广告。每档Pro还附带一个dot（OpenAI的常驻个人代理），首个免费，聊天不占用ChatGPT额度，但它在Codex或Work里发起的任务算。目前EEA、瑞士和英国的Pro用户还拿不到dot。Pro用户另外还有ChatGPT Space、Pages、Codex Security Cloud和Meetings插件（beta）这些DevDay新功能。

Pro 500单独多一项：Agents API with computer use（带电脑操作的Agents API），在Codex和ChatGPT Work里可用，除此之外只有Enterprise才有。

## 额度用完了怎么办：credits、即时重置和两个误会

先澄清误会：撞到额度上限不会终止订阅，也不代表账号被限制，只是对应模型在额度重置前可能暂时不可用，ChatGPT能显示重置时间时会显示出来。这时候可以切换到别的模型，或者等重置。

想继续用，有两条路：

1. 购买credits。在Settings → Usage（Codex里是Usage & Billing）查看余额和购买，credits有效期12个月。支持的场景包括Codex、ChatGPT Work、ChatGPT for Word/Excel/PowerPoint，但不是所有模型和功能都能用credits续。
2. 购买instant reset。根据账单所在国家，Plus和Pro账户可以买一次即时重置，立刻刷新Work和Codex的额度。

客服帮不上忙。官方明确说Support不能重置ChatGPT或Codex的限制，只能核查用量是否被算错、重置后访问有没有恢复。

## ChatGPT Pro值不值：按你卡在哪一档来判断

有一笔账值得先算：在美国区，把每档价格除以用量倍数，Plus、Pro 100、Pro 200、Pro 500摊下来每一倍Plus用量都是20美元。单看单价，三档Pro之间没有谁更划算，区别只在你需要多大的总量。而在此之前，老Pro 200的每倍单价是10美元，这次调整实际上等于单价翻倍，尽管官方的说法是模型效率在提升，同样的额度能比一个月前干更多的活。

判断思路可以很直接：

- **Plus（20美元）**：官方对它的定位是“每周几次专注的编码时段”。偶尔写写代码、做做研究，够用。
- **Pro 100（100美元）**：当Plus的额度开始一周内多次卡住你，这是最小的升级台阶。有GPT-6 Pro、有dot、没有5小时限制。
- **Pro 200（200美元）**：5倍用量不够时再加一档，也是唯一存在“老额度”过渡待遇的档位。
- **Pro 500（500美元）**：个人用户能买到的最大用量，独占Ultrafast和Agents API。如果你的工作对生成速度真的敏感，比如在Codex里大量跑任务，它才有意义；如果只是想要更多总量，多花300美元买一个会把额度烧得飞快的速度档，大概率不值。

一个可操作的检验办法：先用一个月的Plus，记录每次额度卡住你的时间和被耽误的事。一周卡一两次，留在Plus；同一周内反复卡住正经工作，再考虑往上走。

## 常见问题

**ChatGPT Pro支持年付吗？**

不支持。Pro只按月计费，也不能一次预付几个月。

**Pro 100和Pro 200能买到Ultrafast吗？**

不能。上线初期Ultrafast只在Pro 500（以及符合条件的Enterprise和Edu账户）可用，Pro 100/200买credits也不解锁。

**老Pro 200用户退订后重新订阅，还能保住20倍额度吗？**

只要原订阅在2026年9月22日至9月29日上午10点（太平洋时间）之间处于生效状态，重新订阅就能把旧额度用到2026年10月29日；过了这个日期，所有Pro 200统一按10倍Plus的新额度执行，月费不变。

**撞到用量上限需要联系客服重置吗？**

不用，也没用。额度到点会自动重置，客服无法手动重置，只能核查用量是否被错误计算。等重置或者换个模型就行。

**在Pro 500上把Ultrafast当默认模式用划算吗？**

看情况。Ultrafast按8倍速率消耗额度，25倍总量全跑Ultrafast大约等于标准速度下3倍Plus的量。重度依赖速度再开，日常任务用标准模式更耐花。

回到价格本身，ChatGPT Pro现在的定价逻辑其实比一年前清晰：100、200、500三档，每倍用量的单价一致，选哪档只取决于你需要多少总量，以及速度值不值那个溢价。想清楚自己卡在哪，再决定掏多少钱。
